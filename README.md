# Portfolio — Yvette Fabiola Bayi Essoka

Site statique responsive, sans dépendances ni serveur backend. Ouvrir `index.html` dans un navigateur pour le prévisualiser.

## Publier gratuitement avec GitHub Pages
1. Créer un dépôt public nommé `portfolio-data` sur GitHub.
2. Ajouter `index.html`, `style.css` et `script.js` **à la racine du dépôt**.
3. Dans le dépôt : Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
4. Après publication, l'URL sera normalement `https://yvieee28.github.io/portfolio-data/` (si le nom d'utilisateur et le dépôt sont inchangés).
5. Ajouter l'URL dans la rubrique « Sélection » de LinkedIn et dans les coordonnées du profil.

## À personnaliser
- Vérifier que chaque expérience et date reflète exactement le CV.
- Ajouter les liens directs des projets GitHub lorsqu'ils sont publics et prêts à être montrés.
- Les projets sans démonstration publique renvoient vers GitHub ou un contact e-mail ; aucune démonstration fictive n'est présentée.
- Le site ne collecte aucune donnée et n'inclut aucun formulaire backend.
